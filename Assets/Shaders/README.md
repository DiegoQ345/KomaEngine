# Shaders

Shaders del motor (GLSL 460 Core, OpenGL 4.6 Core).

- `basic.vert`: vertex shader minimo (gl_Position fijo).
- `basic.frag`: fragment shader con color fijo.

Las rutas se resuelven desde la ubicacion del ejecutable (Engine/Core/AssetPaths), por lo que funciona ejecutar App.exe tanto desde CMD como con doble clic desde el Explorador.
